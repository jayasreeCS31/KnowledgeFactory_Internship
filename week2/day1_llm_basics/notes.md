## Key Learning

LLMs (Large Language Models) are AI systems trained on large text datasets that can generate human-like responses.

Examples:
- GPT
- Gemma
- Llama
- Mistral

## Prompt Formula

Role + Task + Context + Constraints

Example:

Act as a Java teacher and explain inheritance for beginners in less than 100 words.

## Token

Tokens are smaller text units used by models.

## Temperature

Low → factual output

High → creative output

## Context Window

Amount of conversation memory available to the model.
