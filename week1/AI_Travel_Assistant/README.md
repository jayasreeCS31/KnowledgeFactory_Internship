# AI Travel Assistant

## Project Overview

AI Travel Assistant is a Python-based mini project developed as part of the Knowledge Factory Internship.

The application helps users plan trips by providing:

- Live weather information
- Tourist place recommendations
- Budget estimation
- Travel tips
- Packing suggestions
- Travel history tracking

---

## Features

✔ Weather API integration

✔ Dynamic travel suggestions

✔ Packing recommendations

✔ Budget estimation

✔ Travel score

✔ Travel history using JSON

✔ Modular architecture
